## Phase Goal

**As a** ValorTax case manager, **I want to** nudge clients automatically, offer a cheaper second bank option, and run on a platform that meets security and vendor requirements, **so that** ResSpark can move from the demo to live ValorTax cases.

<objective>
Enforce staff MFA (PROD-02): Supabase TOTP enrollment and verification in the SPA, and an `aal2` requirement on every admin API in the Worker, with a logged reset path for lost devices and a TOTP helper so the automated smoke can still sign in.

Purpose: 16 CFR 314.4(c)(5) requires MFA for anyone accessing customer information, and the Worker is the only data path, so the Worker is where it is enforced. The SPA routing only makes the rule usable.
Output: `aal2` check in `staffAuth`, session-route MFA events, `/admin/mfa/enroll` and `/admin/mfa/verify` (OTP screen copied from upstream shadcn-admin, MIT), shell and error routing, `totp.mjs` with RFC vectors, the demo enrollment and reset scripts, a live Auth test, the staff-token test helper sweep, companion docs.
</objective>
