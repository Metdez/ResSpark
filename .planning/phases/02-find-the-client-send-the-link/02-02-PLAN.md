## Phase Goal

**As a** ValorTax case manager, **I want to** type a phone number, case ID, or email, confirm the matching Logics case, and copy a request link that the client opens on a phone, **so that** I can get a client started in under a minute while still on the call.

<objective>
Build the pure, DB-free Logics read module (fetch client with header parameters, defensive mapper, fixture client, lookup orchestration with phone normalization and the documented-format retry), the shared contact validation both the SPA and the Worker import, and the credential crypto + client resolution that Plans 03 and 04 wire into routes.

Purpose: every unit here is testable without credentials or a database, so the three hardest unknowns of the phase — Logics header auth, phone format acceptance, typo-domain suggestions — are proven before any route exists. The fixture client is what makes the Oct 12 demo possible with no Logics key.
Output: `app/src/lib/contact.ts`, `app/worker/src/integrations/logics/{client,mapper,fixtures,lookup,config}.ts`, `app/worker/src/integrations/credential-crypto.ts`, co-located tests, companion docs.
</objective>
