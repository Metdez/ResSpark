| SMS/email → phone browser → Worker `GET /c/:token` | the link IS the credential (PITFALLS C2) |
| Worker → browser cookie jar | `rs_client` is the client session for Phase 2 |
| Worker → Cloudflare Logs | a failing `/c/<token>` request is the PLAT-08 worst case |
| internet → Worker (bulk guessing) | token enumeration attempts |

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|-----------|----------|-----------|----------|-------------|-----------------|
| T-01-31 | Spoofing | token guessing / enumeration | critical | mitigate | 128-bit random `link_id` + 256-bit HMAC; uniform 404 for every failure; per-IP rate limit (binding or in-memory fallback); `client-link.test.ts` proves identical 404 bodies |
| T-01-32 | Information disclosure | token leaking via Referer, caches, search indexing, or logs | critical | mitigate | Worker-first exchange → cookie → 302 to a token-free URL; `Referrer-Policy: no-referrer`, `Cache-Control: no-store`, `X-Robots-Tag: noindex` on every `/c/*` response; `routePath` logging + invocation logs off; `logger.test.ts` asserts no token in the line |
| T-01-33 | Spoofing | forged `rs_client` cookie | high | mitigate | Hono signed cookie with a key derived from `CLIENT_LINK_HMAC_KEY` (`:cookie` suffix, distinct from the link MAC key), `HttpOnly; Secure; SameSite=Lax`, 24 h `Max-Age`; value carries only `link_id` + `exp` |
| T-01-34 | Information disclosure | timing side-channel on MAC comparison | medium | mitigate | `crypto.subtle.verify` (constant-time) — never `===` on MAC bytes; the length check short-circuits before any DB lookup for malformed tokens |
