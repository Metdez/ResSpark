## Phase Goal

**As a** ValorTax case manager, **I want to** push approved documents into the client's Logics case with one click, **so that** the file is complete in the system of record without downloading and re-uploading by hand.

<objective>
Build the PUSH-02 normalization as pure, parameterized modules that run without the Workers runtime: a greedy PDF splitter that keeps the last good save under the gate, a JPEG/PNG-to-PDF wrapper driven by magic bytes, and the `normalizeForLogics` orchestrator that names parts and hashes them. Install the one new package. Fixtures are generated at test time because every `examples/` PDF is 2–3 KB.

Purpose: the consumer (Plan 03) must never post a part over 5,767,168 bytes and must flag what it cannot shrink; these modules are the whole of that guarantee and are testable with a tiny `targetBytes`.
Output: `@cantoo/pdf-lib@2.11.1` installed; `worker/src/pdf/{test-fixtures,split-pdf,image-to-pdf,normalize-for-logics}.ts` with tests and companion docs.
</objective>
