## Phase Goal

**As a** ValorTax settlement officer, **I want to** review a 433-A worksheet pre-filled from connected bank, payroll, intake, and Logics data with IRS standards for the client's county, **so that** I only confirm values and read the recommendation instead of retyping the form.

<objective>
Export a run as a screening-worksheet PDF labeled "Not an IRS form" on every page, store it as a case document, and push it to Logics through the existing push card and ledger. Per D-16, open question 3.

Purpose: FORM-06 — the case manager files the worksheet in Logics with one click, the same way as every other document, and nobody can mistake it for a signed IRS form.
Output: `worksheet/{text,layout,render,store}.ts`, `routes/admin-worksheet.ts`, push-eligibility change in `db/logics-pushes.ts`, the `433-A worksheets` group in the push card, tests, docs.
</objective>
