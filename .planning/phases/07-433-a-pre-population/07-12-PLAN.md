| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |

| T-07-48 | Denial of service | many or large PDFs | medium | mitigate | 25-document and 10 MB caps; sequential processing; undecodable streams skipped |
| T-07-49 | Elevation of privilege | extracting another case's documents | high | mitigate | case read filtered by `firm_id`; documents selected by that `case_id` only |
| T-07-50 | Information disclosure | document content to an LLM or the browser | high | mitigate | no LLM code path; errors reduced to fixed reason codes; event payload counts only |
