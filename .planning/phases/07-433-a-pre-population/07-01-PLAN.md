## Phase Goal

**As a** ValorTax settlement officer, **I want to** review a 433-A worksheet pre-filled from connected bank, payroll, intake, and Logics data with IRS standards for the client's county, **so that** I only confirm values and read the recommendation instead of retyping the form.

<objective>
Port the deterministic Python engine to TypeScript as a pure Worker module (`app/worker/src/engine/`) and prove it identical to the Python oracle with golden fixtures. Per D-01..D-04: a stdlib Python exporter records, for every case, the inputs, every expected output, and the exact standards-call sequence; the TS parity test replays that sequence and asserts `toEqual`. `app/shared/questions.ts` holds the 28 question declarations the engine and (later, Plan 08) the SPA share.

Purpose: FORM-01. Every later plan (evaluation route, worksheet, staff view) imports these modules; a wrong port here would silently change a recommendation that is signed under penalty of perjury. Python stays the oracle and is never edited.
Output: exporter + generated `golden.json`; six engine modules; shared question module; parity test with purity block; `pnpm check` freshness gate and a `test:live:file` script later plans use; companion docs.
</objective>
