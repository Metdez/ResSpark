## Phase Goal

**As a** ValorTax settlement officer, **I want to** review a 433-A worksheet pre-filled from connected bank, payroll, intake, and Logics data with IRS standards for the client's county, **so that** I only confirm values and read the recommendation instead of retyping the form.

<objective>
Give staff the API behind the 433-A view: read every line with its status and competing proposals, confirm or edit a value, and run the engine against the county's standards with the result recorded immutably. Per D-06, D-11, D-14, D-15, D-19, D-20.

Purpose: FORM-04 (only accepted values reach `case_financial_data`, unknowns stay null and block) and FORM-05 (county standards + recommendation with its math). The SPA (Plan 09), the worksheet (Plan 06) and the proposers (Plans 05, 07) build on these routes and the run shape.
Output: bundle repository, line metadata, view assembly, evaluation module, the admin route file mounted in `index.ts`, unit + live tests, companion docs.
</objective>
