# `app/worker/src/webhooks/docuseal.test.ts`

Unit tests for `docuseal.ts` (Plan 06-04). Bodies are the `test/fixtures/docuseal/webhook_form_completed.json` text, signed with `test/helpers/docuseal-sign.ts` under a fixed unit secret; the timestamp argument moves the signature inside or outside the 300-second window. `Date` alone is faked and pinned to `2026-10-11T12:00:00.900Z` before every test (real timers restored after), so `now()`, the helper's default timestamp and the adapter's `Date.now()` check all read the same instant; with the real clock, a run stalled for a fraction of a second under parallel load pushed the 299 s case past 300 s and the +301 s case inside the window. The `.900` fraction keeps the adapter's unfloored comparison honest: 299 s old is 299.9 s, still accepted. No network and no database. The cases are listed in `docuseal.md` under Tests.
