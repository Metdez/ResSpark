# `app/worker/src/pdf/transactions-statement.ts`

Builds the monthly **Transaction statement** PDF that stands in for a bank statement when the bank provides none (Oct 12 ValorTax call, 19:24–20:52: "I can write something that creates a PDF based off the transactions"). It follows the worksheet split exactly: a pure layout that returns pages of positioned lines, and a thin pdf-lib render. No database, no bindings, no logging.

## Input

| Field | Meaning |
|-------|---------|
| `accountName`, `mask` | From `bank_accounts.name` / `mask`; the account line reads `{name or Account} ••{mask}`. |
| `year`, `month` | The statement month. |
| `transactions[]` | `{ date, name, merchant_name, amount, pending }` rows from `bank_transactions`. The caller drops pending rows; the layout prints what it is given, sorted by `date` ascending. |

## Exports

| Part | What it does |
|------|--------------|
| `DOC_TITLE` | `Transaction statement (generated by ResSpark)`, the PDF's Title metadata. |
| `HEADER_TEXT` | `Transaction statement — Not an official bank statement`, printed bold at 9 pt on every page. |
| `DISCLAIMER` | `Generated by ResSpark from the bank-provided transaction feed. Not an official bank statement.` Printed as a paragraph on page 1 and again in the footer of every page, followed by `Page k of n`. |
| `longMonth(year, month)` | `September 2026`; the title line and the job's display name use it. |
| `signedMoney(amount)` | Plaid sign convention: a positive amount is money **out** and prints `-$12.34`; a negative amount is money **in** and prints `+$1,000.00`; zero prints `$0.00`. |
| `totals(transactions)` | `{ moneyIn, moneyOut, net }`, each rounded to the cent; `net = moneyIn - moneyOut`. |
| `layoutTransactionStatement(input, measure)` | Pure. Letter page (612 × 792), 60 pt margins, 12 pt body, 16 pt leading. Page 1 starts with the bold 16 pt title `Transaction statement — {Month YYYY}`, the account line, the wrapped disclaimer, then the bold column header `Date | Description | Amount`. One row per transaction: ISO date, `merchant_name ?? name ?? '—'` shortened with `fit` to the column, amount right-aligned at the margin. After a spacer: `Money in`, `Money out` and bold `Net` (a negative net prints `-$40.00`). Rows flow onto new pages greedily; the column header and the totals block carry a `keep` so neither ends a page. The result is `WorksheetPage[]`, the same `{ text, x, y, size, bold?, align? }` shape as `worksheet/layout.ts`, so the render loop is identical. |
| `renderTransactionStatement(input)` | Embeds Helvetica and Helvetica-Bold, measures with `widthOfTextAtSize`, draws every line (right-aligned lines at `x - width`), sets the title and producer, saves with `objectsPerTick: Infinity`. Returns the `Uint8Array`. |

Reused from the worksheet: `fit`, `wrap` and the `Measure` / `WorksheetLine` / `WorksheetPage` types from `../worksheet/layout`, and `money` / `toWinAnsi` from `../worksheet/text`. Every string goes through `toWinAnsi`, so a merchant name outside Windows-1252 prints `?` instead of throwing in the standard fonts.

## Notes

- pdf-lib's `save()` rewrites the Producer to its own name unless metadata updates are disabled; `setProducer('ResSpark')` is kept for parity with `worksheet/render.ts`, and the Title does persist.
- The document is text only: no form fields, no images, no official bank artwork. Its header, disclaimer and footer all say it is not an official statement, so nobody can mistake it for one in Review or in Logics.
