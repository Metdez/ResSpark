# `app/src/routes/c/sign.$itemId.tsx`

File route `/c/sign/$itemId` (Plan 06-06, D-14). Renders `SignPage` with the `itemId` path param.

- A direct child of `__root` like the other `/c/*` routes, so it renders outside any card layout and never loads the admin shell.
- `/c/sign/<id>` has two path segments, so the Worker's `GET /c/:token` exchange never matches it; the Worker serves it through the SPA fallback with the client headers and CSP (`run_worker_first` covers `/c/*`).
- With `autoCodeSplitting` the route and `SignPage` are their own chunk; `@docuseal/react` is a further lazy chunk inside `DocusealEmbed`.
- The item id is not validated here; the Worker's start route returns 404 for anything that is not a UUID belonging to this link's request.
- `routeTree.gen.ts` is regenerated by the TanStack router plugin (or `@tanstack/router-generator` directly) and committed.
